BEAN SCOPE:-
Singeleton (Default):- <bean id="alien1" class = "com.gulshan.Alien" scope="singleton" > </bean>
Only ONE object is created. All references point to the same object.

Prototype Scope :- <bean id="alien1" class = "com.gulshan.Alien" scope="prototype" > </bean>
Every getBean() call creates a new object.

SETTER INJECTION :-
Spring injects values using setter methods.

Class Alien.java:-
public class Alien {
    private int age;
    public void setAge(int age){
        this.age = age;
    }
}

spring.xml:-
<bean id="alien1" class="com.telusko.Alien">
    <property name="age" value="21"/>
</bean>

Spring internally does:
Alien a = new Alien();
a.setAge(21);

REF ATTRIBUTE:-
In the spring.xml in the <property> tag if we want to assign to a primitive type we use value.
but If we want to assign a reference or an object we use "ref"  here  ref ="lap1"  in which we assign the id of that particular object we want to connect the bean with  this avoids creating objects manually
also the bean must be created or should exist  before passing its id to " ref "of another bean.
This is a part of setter injection.

 <bean id="alien1" class = "com.gulshan.Alien" >
    <property name ="age" value ="21"> </property>
    <property name ="lap"  ref ="lap1"> </property>
    </bean>

    <bean id="lap1" class = "com.gulshan.Laptop"> </bean>

CONSTRUCTOR INJECTION:-
instead of using setter injection we can use constructor injection as well which can be done as soon as we have the object created
<constructor-arg value="21"> </constructor-arg>
 we can assign the value using the constructor-arg as well this is difine s inside the spring.xml file itself

    NOTE:-
             <property name ="lap"  ref ="lap1"> </property>
             <constructor-arg value="21"> </constructor-arg>

       this was working when it was single parameterized constructor in alien but wo double parametrized constructor we need to use something else i.e instead of using setter injection here using property
       we can use   <constructor-arg ref="lap1"> </constructor-arg>

    NOTE:-
       In Constructor injection the values are passed based on the order of parameters in the constructor means if
       alien(int age , Laptop lap){
       this.age = age;
       this.lap = lap;
       }
       then  in the spring.xml we cant inject values in the order
               <constructor-arg name="lap" ref="lap1"> </constructor-arg>
               <constructor-arg name="age" value="21"> </constructor-arg>
            here lap is injected first and then age so there are several ways to avoid it which are by using the type and index (Preferred) attribute this avoids the order based error
