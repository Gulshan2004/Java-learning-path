Model-View-Controller (MVC):
● Model: Represents application data and business logic.
● View: The presentation layer (e.g., JSP files).
● Controller: Handles user requests and interacts with the model to return
responses.
POJO (Plain Old Java Object): A simple Java class used to encapsulate data.

MODEL ATTRIBUTE:
The @ModelAttribute annotation is designed to bind form data from
an incoming request to a model object in a web application,
enabling the seamless transfer of user input into your application's
 data structure. This connection is essential for handling user-submitted
information effectively, making your selection correct.


DISPATCHER SERVLET:
The DispatcherServlet acts as the central hub for processing
HTTP requests in a Spring web application,
routing these requests to the appropriate handlers and ensuring that
responses are generated and returned to the client. By managing requests centrally,
it simplifies the request handling process, promoting a clear structure and better
organization within the application.

The 'web.xml' file is essential for configuring the DispatcherServlet in a Spring MVC
application as it defines the servlet and its mapping, allowing
the application to route requests correctly. This is a fundamental aspect
of understanding how Spring manages web requests, reinforcing your
grasp of the framework’s architecture.
